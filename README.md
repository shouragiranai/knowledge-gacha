# 知識ガチャ

Wikipedia(日本語版)のランダム記事を使って、4択クイズで色々な分野の知識に触れるスマホ向けWebアプリです。
読み流しで終わらせず、クイズに答えてから記事の要約を読むことで記憶に残すことを狙っています。

## 機能

- **クイズ**(1問ごとにランダム記事を1件引き、似た記事を検索して選択肢を作る)
  - 「この説明はどの記事?」:要約の記事名を「〇〇」に伏せて出題(冒頭の読み仮名も除去)
  - 「この画像は何?」:サムネイルがある記事のみ。画像を見て4択
  - 選択肢は Wikipedia 検索の「似た記事」(`morelike:`)から選ぶので、同じ分野の紛らわしい選択肢になります
    - 正解と名前が重なる記事・説明文に出てくる語・曖昧さ回避や一覧は除外
    - 検索に失敗したときはランダム記事で代用
  - 「分からない」ボタンで答えを見られます(不正解扱いで復習リストに入ります)
  - 次の問題を裏で先読みするので、待ち時間がほぼありません
  - 要約が50字未満の記事・曖昧さ回避ページは除外
- **回答後の画面**:正解/不正解のハンコ風アニメーション、要約全文・画像・「Wikipediaで読む」リンク、「☆ 気になる」保存
- **気になるリスト**:保存した記事の一覧と削除
- **復習**:間違えた問題を同じ問題のまま解き直せます(選択肢の順番は毎回変わります)。正解すると一覧から外れます
- **成績**:今日解いた数・正答率・連続正解数・最高連続正解・通算成績・直近7日間のグラフ

データはすべてブラウザの `localStorage` に保存されます(サーバー不要・ログイン不要)。

## 構成

HTML / CSS / JavaScript だけの静的サイトです。フレームワークもビルドも不要です。

```
index.html      画面の骨組み
css/style.css   和風デザイン(明朝体の見出し、和紙風の背景)
js/wiki.js      Wikipedia REST API からランダム記事を取得・フィルタ
js/quiz.js      記事から問題を組み立てる(記事名の伏せ字化など)
js/storage.js   localStorage(気になる・間違えた問題・成績)
js/app.js       画面の切り替えと操作
icon.svg        ファビコン
.nojekyll       GitHub Pages で Jekyll 処理を無効化
```

使用API(どちらもAPIキー不要):
- ランダム記事:`https://ja.wikipedia.org/api/rest_v1/page/random/summary`
- 似た記事の検索:`https://ja.wikipedia.org/w/api.php?action=query&list=search&srsearch=morelike:<記事名>&origin=*`

## ローカルで動かす

ローカルサーバー経由で開いてください(`index.html` を直接開くと、ブラウザによっては通信や保存が制限されます)。

```sh
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

スマホ実機で試す場合は、同じWi-Fiにつないで `http://<PCのIPアドレス>:8000` を開いてください。

## GitHub Pages で公開する

1. このリポジトリを GitHub に push する(公開したいブランチ、例: `main` に内容をマージしておく)
2. GitHub のリポジトリページで **Settings → Pages** を開く
3. **Build and deployment** の **Source** を「**Deploy from a branch**」にする
4. **Branch** で公開するブランチ(例: `main`)とフォルダ「**/ (root)**」を選び、**Save**
5. 1〜2分待つと、ページ上部に公開URL(`https://<ユーザー名>.github.io/knowledge-gacha/`)が表示されます

更新するときは、そのブランチに push するだけで自動的に再公開されます。

> 補足:無料プランの GitHub Pages は公開リポジトリが対象です。非公開リポジトリで使う場合は有料プランが必要です。

### ホーム画面に追加

スマホのブラウザで公開URLを開き、共有メニューから「ホーム画面に追加」するとアプリのように起動できます。
